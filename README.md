# RPi Router Control for Windows

Windows-клиент для Raspberry Pi Router API.

Стек:

- Python
- PySide6
- requests

## Версия 0.2

Реализовано:

- подключение к Raspberry Pi API;
- просмотр пользователей;
- создание пользователя;
- переименование пользователя;
- удаление пользователя;
- выбор access_mode;
- получение текущего расчётного состояния через /access/<user_id>;
- просмотр зарегистрированных устройств;
- просмотр обнаруженных DHCP/Wi-Fi клиентов.

## Access mode

Клиент использует значения API без собственной логики:

- schedule
- always_allow
- always_block

Расчёт разрешённого доступа выполняет Raspberry Pi.

## Установка на Windows

Создать виртуальное окружение:

    python -m venv .venv

Активировать:

    .venv\Scripts\Activate.ps1

Установить зависимости:

    pip install -r requirements.txt

Запустить:

    python main.py

В поле API указать адрес Raspberry Pi, например:

    http://192.168.10.1:8080
