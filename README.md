# RPi Router Control for Windows

Windows-клиент для Raspberry Pi Router API.

Стек:

- Python
- PySide6
- requests

Используется минимальный пакет `PySide6-Essentials`; WebEngine и PDF-модули
этому приложению не требуются.

## Версия 0.2

Реализовано:

- подключение к Raspberry Pi API;
- просмотр пользователей;
- создание пользователя;
- переименование пользователя;
- удаление пользователя;
- выбор access_mode;
- получение текущего расчётного состояния через /access/<user_id>;
- просмотр зарегистрированных устройств;
- просмотр обнаруженных DHCP/Wi-Fi клиентов.

## Access mode

Клиент использует значения API без собственной логики:

- schedule
- always_allow
- always_block

Расчёт разрешённого доступа выполняет Raspberry Pi.

## Установка на Windows

Создать виртуальное окружение:

    python -m venv .venv

Активировать:

    .venv\Scripts\Activate.ps1

Установить зависимости:

    pip install -r requirements.txt

Запустить:

    python main.py

В поле API указать адрес Raspberry Pi, например:

    http://192.168.0.2:8080

Клиент подключается к роутеру напрямую и не использует системный HTTP-прокси,
чтобы локальные адреса не давали ложную ошибку `502`.

Для создания, изменения и удаления данных введите API-токен в маскированное
поле «Токен». Получить его можно локально на Raspberry Pi:

    sudo sed -n 's/^RPI_ROUTER_API_TOKEN=//p' /etc/rpi-router-api.env

После ввода адрес и токен сохраняются в пользовательских настройках Windows и
восстанавливаются при следующем запуске. Значения также можно задать при первом
запуске через переменные окружения `RPI_ROUTER_API_URL` и
`RPI_ROUTER_API_TOKEN`. Токен не хранится в исходном коде и не отправляется с
GET-запросами.

Токен не шифрует HTTP-трафик. Используйте клиент напрямую только в доверенной
домашней сети; для доступа через интернет потребуется HTTPS или приватный VPN.
